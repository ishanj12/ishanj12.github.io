ngrokd Quickstart

Get private endpoints accessible on your machine in minutes

ngrokd is a forward proxy daemon that discovers your ngrok bound endpoints and creates local access points for them via mTLS.

What you'll need

  • An ngrok account with an API key
  • Kubernetes bound endpoints created in the ngrok dashboard
  • Root/sudo access on your machine

1. Install ngrokd

curl -fsSL https://raw.githubusercontent.com/ngrok/ngrokd/main/install.sh | sudo bash
curl -fsSL https://raw.githubusercontent.com/ngrok/ngrokd/main/install.sh | sudo bash
docker pull ngrok/ngrokd:latest

2. Start the daemon

sudo ngrokd install
sudo ngrokd start
sudo ngrokd install
sudo ngrokd start
docker run -d \
  --name ngrokd \
  --cap-add=NET_ADMIN \
  -e NGROK_API_KEY=your_api_key \
  -v ngrokd-data:/etc/ngrokd \
  ngrok/ngrokd:latest
docker run -d \
  --name ngrokd \
  --cap-add=NET_ADMIN \
  -e NGROK_API_KEY=your_api_key \
  -p 8081:8081 \
  -p 80:80 \
  -p 443:443 \
  -v ngrokd-data:/etc/ngrokd \
  ngrok/ngrokd:latest

Set listen_interface: "0.0.0.0" in config for network mode.

3. Set your API key

ngrokctl set-api-key YOUR_NGROK_API_KEY
docker exec ngrokd ngrokctl set-api-key YOUR_NGROK_API_KEY

4. Verify

ngrokctl status
ngrokctl list
curl http://your-endpoint/
docker exec ngrokd ngrokctl status
docker exec ngrokd ngrokctl list
curl -H "Host: your-endpoint" http://localhost:80/

5. Configure (optional)

The configuration file is located at /etc/ngrokd/config.yml. Here's a minimal example:

api:
  key: ""  # Set via ngrokctl set-api-key

bound_endpoints:
  poll_interval: 30

net:
  listen_interface: virtual  # "virtual" or "0.0.0.0"
  start_port: 9080

server:
  log_level: info
  health_port: 8081
